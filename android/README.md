# PixAI Android

نسخهٔ Native اندروید PixAI با رابط گفت‌وگوی مینیمال و الهام‌گرفته از تجربهٔ چت‌بات‌های مدرن.

## امکانات
- گفت‌وگوی فارسی با PixCore 1
- تاریخچهٔ محلی گفتگوها
- گفتار به متن فارسی از طریق سرویس تشخیص گفتار اندروید
- قابلیت‌های متصل به Worker از مسیر چت، در صورت فعال بودن سرویس مربوطه
- بدون WebView و بدون صفحهٔ واردکردن توکن یا تنظیمات فنی

## ارتباط و امنیت
اپ از Worker عمومی مخصوص موبایل استفاده می‌کند و هیچ کلید یا توکن محرمانه‌ای داخل APK قرار ندارد. دسترسی عمومی فعلاً محدودیت آزمایشی دارد: حداکثر ۴۰ درخواست در روز برای هر IP و هر نصب، و ۸ درخواست در دقیقه برای هر IP. این محدودیت‌ها برای کنترل مصرف سرویس هستند و جایگزین سامانهٔ کامل ضدسوءاستفاده برای انتشار گسترده نیستند.

## ساخت
از پوشهٔ android دستور `gradle assembleDebug` اجرا شود. خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## پیش از انتشار عمومی
نسخهٔ فعلی یک build آزمایشی است. قبل از انتشار در بازار باید تست روی چند دستگاه، بررسی سیاست حریم خصوصی، محدودسازی مصرف و هزینهٔ سرویس‌های AI، و تکمیل صفحهٔ پشتیبانی و اطلاعات ناشر انجام شود.
